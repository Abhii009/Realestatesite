# Aravali Realty (Jaipur property website)

Single-file site: `index.html` (Tailwind, Lucide, Lenis via CDN, so internet is required).

## Run in VS Code
1. File > Open Folder > select this folder.
2. Install the recommended "Live Server" extension.
3. Right-click `index.html` > "Open with Live Server".

## Edit
- Properties: the `PROPS` array in the `<script>` section.
- Phone / WhatsApp number: search for `919829000000`.
- Colors: the `tailwind.config` block near the top.
